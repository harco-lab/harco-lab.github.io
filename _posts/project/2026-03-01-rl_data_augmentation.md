#### Goal of This Project

- Build a pipeline that expands real teleoperation demonstrations with simulation data, for training robust manipulation skill models.
- Learn manipulation policies with reinforcement learning in a simulation environment aligned with the real setup.
- Make skill models robust to out-of-distribution conditions in the real environment.

***

#### Project Contents

- A real-to-sim environment that matches the real dual-arm hand robot setup
- A hybrid controller that combines reinforcement learning for grasping with imitation-learning policies
- Domain-randomized simulation data used together with real demonstrations to train manipulation skill models, evaluated on the real robot
